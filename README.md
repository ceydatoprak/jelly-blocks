# Jelly Blocks

A mobile-friendly jelly block puzzle game prototype built with HTML, CSS and JavaScript.

The game focuses on placing colorful jelly-shaped blocks on the board, clearing rows and columns, building combos and collecting stars.

## Play

🎮 [Play Jelly Blocks](https://ceydatoprak.github.io/jelly-blocks/)

## Features

- Drag-and-drop block placement
- Mobile touch controls
- Score and combo system
- Jelly-style animations and visual effects
- Sound effects and haptic feedback
- Star progression system
- Masterpiece Rush mini-game
- Gallery and unlockable paintings
- Local progress saving

## Technologies

- HTML5
- CSS3
- JavaScript
- Git / GitHub
- GitHub Pages
